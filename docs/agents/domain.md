# Domain docs

Single-context repo. The live app is Astro in `web/`.

## Before exploring, read

- `CONTEXT.md` at the repo root (club words)
- `README.md` for layout and how to run the app
- `docs/adr/` for decisions in the area you are touching

If a term you need is missing from `CONTEXT.md`, do not invent a synonym. Note the gap.

If your change contradicts an ADR, say so instead of silently overriding it.
